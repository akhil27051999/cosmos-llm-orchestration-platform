Helios — End-to-End Architecture

Cloud-Native LLM Orchestration Platform · how a request flows from edge to model to storage

A client submits a job at the edge → the FastAPI gateway accepts it instantly (202 + id) → it's queued on the Kafka event backbone → a Go worker runs the agent loop against Claude, wrapped in resilience (rate-limit · breaker · retry · fallback) → results stream back over SSE and persist across the polyglot stores — all running on Kubernetes, shipped by GitOps, observed end-to-end.
